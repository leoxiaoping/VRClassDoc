# 什么是小瓶 VR 课堂？

小瓶 VR 课堂是一款专为教育场景设计的虚拟现实(VR)教学平台。通过先进的 VR 技术，我们致力于为师生打造一个沉浸式、互动性强的虚拟教学环境。

在小瓶 VR 课堂中，每位用户拥有唯一的空间 ID，可通过官网进行课件制作和管理，包括上传 PPT 课件、3D 模型、视频、音频及 3D 场景贴图等多媒体素材，并对每页课件进行个性化设计。完成制作后，用户可在 VR 设备中通过空间 ID 获取并播放自己专属的课件内容。

## 核心优势

- **沉浸式教学体验**：借助 VR 技术打造身临其境的学习环境，显著提升学习兴趣和效果
- **云端同步管理**：通过个人空间 ID 实现课件云端存储，支持官网编辑与 VR 设备播放无缝同步
- **丰富多媒体支持**：全面支持 PPT、3D 模型、视频、音频等多种媒体格式，每页课件均可独立设置
- **操作简单易用**：界面简洁直观，教师无需复杂培训即可快速上手制作 VR 课件
- **个性化课件制作**：可根据不同学科和教学需求，灵活定制专属 VR 教学内容

## 适用场景

- 学校课堂教学
- 实验室模拟操作
- 远程在线教育
- 职业技能培训

小瓶 VR 课堂旨在革新传统教学模式，让学习变得更加生动有趣且高效。
