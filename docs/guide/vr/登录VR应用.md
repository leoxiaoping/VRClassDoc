# 登录VR应用

你将学会：  
☐ 打开小瓶VR课堂应用  
☐ 输入你的空间 ID  
☐ 验证是否成功进入自己的课件库

预计用时：3 分钟  
前置条件：已安装小瓶VR课堂应用，已获取空间 ID

---

### 先确认：空间 ID 准备好了吗？

空间 ID 是你在后台看到的那串字母数字（例如 `pbottle`）。

> 如果还没拿到空间 ID，先在电脑上完成：[登录后台](../backend/登录后台.md) 第 3 步有详细说明。

---

### 第 1 步：打开小瓶VR课堂应用

1. 在 VR 头显主界面进入 **「应用库」**。
2. 找到 **小瓶VR课堂** 图标，用准星瞄准后扣动扳机键打开。

> 首次打开可能会请求存储权限等，全部点击「允许」即可。

---

### 第 2 步：找到空间 ID 设置入口

1. 进入应用后，你会看到主界面（此时默认使用官方空间 ID：`pbottle`，展示的是官方示例课件）。
2. 找到桌面上的 **「设置」** 按钮，用准星点击进入。
3. 在设置页面中找到 **空间 ID 输入框**。

---

### 第 3 步：输入你的空间 ID

1. 用准星点击输入框，调出虚拟键盘。
2. 删除默认的空间 ID，输入 **你自己的空间 ID**。
3. 仔细核对大小写和字符，确保准确无误。
4. 点击输入框后面的 **「✔」**（确认）按钮。

> 预期结果：页面刷新，课件列表变成你自己的课件。  
> 如果没变化：检查空间 ID 是否输入正确（区分大小写）。如果 ID 确认无误仍不行，联系客服检查账号绑定状态。

---

### 第 4 步：确认登录成功

- 默认空间 ID（`pbottle`）显示的是官方示例课件。
- 换成你的空间 ID 后，应该能看到你自己上传的课件。
- 如果看到你的课件出现在列表中，说明登录成功。

> 💡 下次打开应用会自动记住你的空间 ID，不用重复输入。

---
