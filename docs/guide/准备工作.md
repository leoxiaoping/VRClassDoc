# 准备工作

## 获取应用

- 方式一：通过 [应用商店地址](https://store.picoxr.com/cn/detail/1/7546489817597558799) 获取
- 方式二：在 [PICO 商店](https://store.picoxr.com/cn/) 中搜索"小瓶 VR 课堂"获取

## 获取空间 ID

1. 访问[小瓶 VR 课堂官网](https://vr.pbottle.com/class/)，进入登录页面
   ![登录页面](../public/Snipaste_2025-11-21_10-09-59.png "登录页面")

2. 注册账号或使用现有账号登录，登录后会自动进入 VR 课件中心
   ![VR 课件中心首页](../public/Snipaste_2025-11-21_10-17-11.png "VR 课件中心首页")

3. 在课件中心首页找到【当前课堂 ID】，此即为您的空间 ID
   ![当前课堂 ID](../public/Snipaste_2025-11-21_11-01-30.png "当前课堂 ID")
