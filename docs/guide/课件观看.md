# 课件观看

本文档将详细介绍如何使用小瓶 VR 课堂客户端在 VR 设备中观看课件内容，让您充分享受沉浸式学习体验。

## 观看课件步骤

### 1. 切换空间 ID

空间 ID 是访问您专属课件的关键标识，每个用户都有唯一的空间 ID。

操作步骤：

- 启动小瓶 VR 课堂客户端
- 默认情况下系统会显示官方空间 ID：pbottle
- 点击桌面设置按钮进入设置页面
- 在输入框中输入您的个人空间 ID
- 点击输入框后的"✔"确认按钮完成切换
- 切换成功后，下次启动小瓶 VR 课堂客户端时将保持使用您设置的空间 ID

> 提示：您的空间 ID 可在小瓶 VR 课堂官网的课件中心首页找到，标记为"当前课堂 ID"。

### 2. 选择课件

切换到正确的空间 ID 后，您可以浏览和选择要观看的课件：

- 在 VR 环境中启动小瓶 VR 课堂客户端
- 系统将显示对应空间 ID 下的课件列表
- 若使用默认的官方空间 ID (pbottle)：显示官方提供的课件
- 若使用个人空间 ID：显示您自己上传和制作的课件
- 使用手柄摇杆上下滚动浏览课件列表
- 找到想要观看的课件后，将准星对准课件封面并扣动扳机键确认选择

### 3. 观看课件

进入课件后，您可以使用手柄进行各种操作：

基本操作：

- **翻页**：使用手柄扳机键点击屏幕下方的翻页按钮前进或后退
- **视频控制**：对于包含视频的课件，可以通过扳机键控制视频的播放/暂停、调节进度、调整播放速度和音量
- **返回**：任何时候都可以通过返回主页按钮回到课件选择主页

## VR 操作指南

为了更好地使用小瓶 VR 课堂，以下是详细的 VR 操作方法：

### 导航操作

- **列表滚动**：使用手柄上的摇杆上下滑动来滚动课件列表
- **视角转换**：自然地转动头部即可改变观察视角，全方位查看课件内容
- **选择确认**：将准星对准目标元素后，扣动手柄扳机键进行选择或确认操作

### 交互操作

- **课件选择**：在课件列表中将准星对准课件封面并扣动扳机键
- **页面翻页**：在课件播放界面，对准翻页按钮并扣动扳机键
- **元素交互**：对于可交互的 VR 元素，使用相同的方式进行操作

## 观看技巧与建议

1. **环境准备**

   - 确保观看环境安全，清除可能碰撞的障碍物
   - 调整 VR 设备至舒适佩戴状态
   - 确保充足光线以便识别物理环境边界

2. **操作习惯**

   - 初次使用时，建议先熟悉手柄的基本操作
   - 操作时保持手柄稳定，提高选择准确性
   - 长时间使用时注意适当休息，避免眩晕感

3. **技术保障**
   - 确保网络连接稳定，特别是观看高清视频课件时
   - 定期更新小瓶 VR 课堂客户端至最新版本
   - 如遇技术问题，及时联系技术支持团队

## 注意事项

1. **健康提醒**

   - 建议每次连续观看不超过 30 分钟
   - 观看过程中如感到不适，请立即停止使用
   - 儿童使用时需在成人监护下进行

2. **设备维护**

   - 使用完毕后妥善存放 VR 设备
   - 定期清洁设备镜片和面部接触部分
   - 避免设备受到强烈撞击或跌落

3. **网络要求**
   - 建议使用稳定的 Wi-Fi 网络
   - 网络带宽不足时可能影响课件加载速度
   - 大型课件建议在网络环境良好的情况下下载缓存
