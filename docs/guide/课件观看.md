# 课件观看

## 1. 选择课件

- 登录成功后，您将看到可观看的课件列表
- 浏览列表并选择想要观看的课件
- 点击课件封面进入课件

### 3. 观看课件

- 使用手柄操作浏览课件内容
- 按照课件设计的顺序或自由浏览方式进行观看
- 可通过菜单键暂停、继续或退出课件

## 观看操作指南

- **滚动**：使用手柄摇杆控制课件列表滚动
- **转向**：转动头部进行视角转换
- **交互**：扣动手柄扳机键可：选择课件、翻页、输入空间 ID 等操作
- **返回**：使用手柄扳机键在返回主页按钮单击可返回课件选择列表界面

## 注意事项

1. 确保网络连接稳定，以获得流畅的观看体验
2. 在观看前检查 VR 设备佩戴是否舒适
3. 控制观看时间，适时休息以保护视力
4. 如遇到加载缓慢问题，请检查网络状况或联系技术支持

现在您可以开始享受沉浸式的 VR 课件观看了！
