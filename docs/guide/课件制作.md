# 课件制作

1. 在课件管理页面中，点击"编辑 VR 元素"按钮进入编辑页面

   ![编辑页面](../public/Snipaste_2025-11-21_13-03-06.png "编辑页面")

   - 编辑页面功能介绍:

     - "公共页面空间"的页面：添加到本页面的元素会在所有页面生效
     - 切换页面: 点击页面的箭头，可切换页面
     - 添加 VR 元素: 点击"添加 VR 元素"按钮可以为当前页面添加 VR 元素

   - 添加 VR 元素页面功能介绍:
     - 添加 VR 元素页面: 切换到想要添加的 VR 元素页面，点击"添加 VR 元素"按钮后会弹出"素材元素选择"页面,
