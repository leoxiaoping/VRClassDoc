# 课件制作

在课件管理页面中，您可以对已上传的课件进行 VR 元素编辑。找到您想要编辑的课件，在操作列点击"编辑 VR 元素"按钮即可进入编辑页面。

![编辑页面](../public/Snipaste_2025-11-21_13-03-06.png "编辑页面")

## 编辑页面功能介绍

1. **公共页面空间**：这是特殊页面，添加到本页面的元素会在所有幻灯片页面中生效，适用于需要在每一页都显示的元素，如 Logo、水印等。

2. **页面切换**：通过点击页面间的箭头按钮，可以在不同幻灯片页面之间切换，为每一页单独添加不同的 VR 元素。

3. **添加 VR 元素**：点击"添加 VR 元素"按钮可以为当前选中的页面添加 VR 元素。

4. **预览元素**：点击"预览"按钮可实时预览当前元素的效果。

5. **移除元素**：如果需要删除某个元素，点击该元素对应的"移除"按钮即可将其从当前页面移除。

## 添加 VR 元素操作步骤

1. 首先切换到您想要添加 VR 元素的具体页面。

2. 点击"添加 VR 元素"按钮，系统会弹出"素材元素选择"窗口。

3. 在"素材元素选择"页面中，您可以看到所有已上传的素材元素，按照素材类型分类展示。

4. 找到您想要添加的素材，点击该素材行尾部的"加入"按钮。

5. 成功添加后，在 VR 设备重新打开该课件后，即可看到添加的元素。

## 使用建议

- 公共元素（如背景音乐、学校 3DLogo 等）建议添加到"公共页面空间"中，避免重复添加。
- 单个页面特有的元素（如特定模型、视频等）添加到对应的具体页面中。
- 建议在添加元素后使用"预览"功能检查效果，确保元素本身正常。
