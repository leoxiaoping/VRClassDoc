# 小瓶VR课堂 使用指南

欢迎使用小瓶VR课堂！本指南将带你从零开始，一步步掌握如何制作和观看沉浸式VR课件。

你将通过**两条主线**完成所有操作：

- 💻 **后台编辑端**：在电脑浏览器上，上传课件素材、制作VR课件。
- 🥽 **VR眼镜端**：在PICO VR头显中，观看和操控你的VR课件。

如果你是第一次使用，建议按顺序从后台编辑端开始。已经上传好课件？直接跳到 [VR眼镜端](/guide/vr/安装VR应用) 开始观看。

### 产品简介

小瓶VR课堂是一个虚拟现实教学平台。简单说：**把你的PPT课件变成沉浸式VR课堂**，还能在课件里加入3D模型、视频、音频和全景图。

核心流程：  
登录后台 → 上传课件和素材 → 给课件添加VR元素 → 在VR眼镜中用空间ID同步 → 沉浸式观看

**空间ID** 是你专属云空间的“门牌号”。只要在VR眼镜里输入你的空间ID，就能看到你的课件。

适用场景：课堂教学、实验模拟、远程教育、职业培训。
