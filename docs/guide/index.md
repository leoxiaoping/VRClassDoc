# 使用指南

欢迎使用小瓶 VR 课堂！本指南将帮助您快速了解和使用我们的 VR 教学平台。

## 产品概述

小瓶 VR 课堂是一款创新的虚拟现实教学平台，通过空间 ID 系统实现云端课件管理和同步。用户可以在官网上创建和编辑课件，包括上传 PPT、3D 模型、视频、音频等多媒体内容，并在 VR 设备中通过空间 ID 访问和播放专属课件。
