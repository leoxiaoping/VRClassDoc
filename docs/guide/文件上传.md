# 文件上传

文件上传是使用小瓶 VR 课堂的第一步，通过上传课件和素材，您可以构建丰富的 VR 教学内容。本文档将详细介绍如何上传课件和素材，以及支持的文件格式。

## 上传课件

课件是 VR 教学的核心内容，通常是以 PDF 格式呈现的演示文稿。通过上传课件，您可以将其转换为沉浸式的 VR 教学体验。

### 进入课件上传界面

1. 登录小瓶 VR 课堂官网，进入课件中心首页

2. 按照下图所示步骤进入新课件上传界面：
   ![新课件界面](../public/Snipaste_2025-11-21_11-08-15.png "新课件界面")

   - 点击左侧菜单栏的"课件库"
   - 在展开的课件库菜单中点击"新课件"

   系统将跳转到课件上传页面，您可以在此页面完成课件上传操作。

### 课件上传详细步骤

![上传步骤](../public/Snipaste_2025-11-21_11-17-30.png "上传步骤")

1. **选择课件文件**（区域"1"）

   - 点击文件选择区域或"Browse"按钮
   - 在弹出的文件选择对话框中，选择您准备好的课件文件
   - 目前仅支持 PDF 格式的课件文件

2. **设置课件名称**（区域"2"）

   - 系统会自动填充文件名作为默认课件名称
   - 您可以根据需要自定义课件名称
   - 建议使用有意义的名称，便于后续管理和查找

3. **提交上传**（区域"3"）
   - 确认文件选择和课件名称无误后，点击"提交"按钮
   - 系统开始上传课件文件，上传过程中请勿关闭页面
   - 上传完成后，您可以在课件管理页面的课件列表中看到刚刚上传的课件

### 课件上传注意事项

- 请确保课件内容符合相关法律法规
- 建议在上传前检查 PDF 文件的质量和完整性
- 大文件上传可能需要较长时间，请保持网络连接稳定
- 上传成功的课件可以在"课件管理"页面进行进一步编辑

## 上传素材

素材是丰富 VR 课件内容的重要元素，包括 3D 模型、视频、音频、场景图资源。通过上传素材，您可以为课件添加交互式 VR 元素。

### 进入素材上传界面

1. 登录小瓶 VR 课堂官网，进入课件中心首页

2. 按照下图所示步骤进入素材库管理页面：
   ![素材库管理页面](../public/Snipaste_2025-11-21_13-15-10.png "素材库管理页面")

   - 点击左侧菜单栏的"素材库"
   - 在展开的素材库菜单中点击"私有素材"

   系统将跳转到素材管理页面，您可以在此页面上传和管理素材。

### 素材上传详细步骤

在素材管理页面，您可以通过以下两种方式上传素材：

#### 方法一：点击上传按钮

- 点击页面中的"➕ 上传素材文件"按钮
- 在弹出的文件选择对话框中选择要上传的素材文件

#### 方法二：拖拽上传

- 准备好需要上传的素材文件
- 直接将文件拖拽到页面中标注的上传区域
- 系统会自动开始上传过程

### 素材上传注意事项

- 建议在上传前对素材进行适当的压缩和优化
- 不同类型的素材有不同的大小限制

## 支持的文件格式

为了确保最佳的 VR 体验效果，小瓶 VR 课堂支持以下特定格式的文件上传：

### 课件格式

- **PDF 文档**（.pdf）：标准的课件格式，支持多页演示

### 素材格式

1. **3D 模型**

   - GLB 格式（.glb）：推荐的 3D 模型格式

2. **视频文件**

   - MP4 格式（.mp4）：标准视频格式，兼容性好，画质优秀

3. **音频文件**

   - MP3 格式（.mp3）：通用音频格式，体积小，音质佳

4. **场景图文件**
   - JPEG 格式（.jpg）：常用图片格式，压缩率高，加载快

### 格式建议

- 上传前请确保文件格式正确，避免上传不支持的格式
- 建议使用专业软件导出标准格式文件
- 对于 3D 模型，建议进行适当的简化以保证 VR 环境中的流畅运行
- 视频文件建议使用 H.264 编码以获得更好的兼容性

## 上传常见问题及解决方案

### 上传失败怎么办？

1. 检查文件格式是否符合要求
2. 确认文件大小未超过限制
3. 检查网络连接是否稳定
4. 刷新页面后重新尝试上传

### 上传速度慢怎么办？

1. 检查当前网络状况
2. 避开网络高峰期进行上传
3. 考虑对大文件进行压缩处理
4. 更换网络环境重试

通过合理使用文件上传功能，您可以快速构建丰富的 VR 教学资源库，为学生提供沉浸式的学习体验。
