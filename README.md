## 项目简介
vrClass 是一款面向教育领域的虚拟现实教学解决方案，提供课件制作与管理功能。本项目包含完整的使用指南和操作文档，帮助教师快速上手使用。

![小瓶VR课堂工作流程图](docs/public/flow.png)

## 核心功能
- 企业级数据加密和隐私保护
- 教学资源安全存储与管理
- 支持 VR 课件制作与播放
- 完善的文件上传及管理流程
